# 🧟 Ultimate Zombie Defense [16-Player MOD]

Language: English | [中文](README.zh-CN.md)

> A powerful multiplayer MOD that enhances gameplay with scaling difficulty, major buffs, and balanced progression for up to 16 players.

---

## 📖 Overview

- Supports up to **16 online players** simultaneously.
- Round difficulty **automatically scales** based on the number of players in the room.
- Player attributes are significantly enhanced while zombie strength is carefully balanced, creating a challenge that remains fair.

## 💎 Player Buffs & Enhancements

### 1. Compound Growth (Every 5 Rounds)

All of the following attributes gain a **+5% cumulative boost every 5 rounds**:

- Player Health & Armor
- Most Skill Tree attributes
- All Weapons (Damage / Fire Rate / Reload Speed / Magazine Capacity / Total Ammo)
- All Structures (Durability / Attack Damage)
- Resources (Gold / Experience Gain)

### 2. Equipment Boosts

| Item | Boost |
|------|-------|
| Primary Weapons | ×2 Damage |
| Special Weapons | ×4 Damage |
| All Weapons | ×2 Magazine Capacity / ×4 Total Ammo |
| Armor | ×2 Armor Strength & Damage Reduction |

### 3. Building & Defense Boosts

| Item | Boost |
|------|-------|
| Mines & Oil Barrels, Autocannons, Tesla Towers, Terminator Towers | ×4 Damage |
| Laser Fences, Medkits, Ammo Crates | ×4 Structure Durability |
| Autocannons, Laser Fences, Tesla Towers, Terminator Towers | ×2 Structure Durability |
| Autocannons | ×4 Output Time |
| Medkits | ×4 Healing Speed |

### 4. Skill Tree Upgrades

| Skill Path | Upgrade |
|------------|---------|
| Heavy - Berserker | Doubled trigger threshold and damage output |
| Medic - Invincibility | Doubled invincibility duration |
| Specialist - Critical Strike | Doubled critical chance and critical damage |
| Engineer | Doubled damage from High-voltage Barbed Wire and Autocannon |

## 🧟 Zombie Balance & Game Progression

- **Smooth Difficulty Curve:** Early-game remains close to vanilla, while mid- and late-game difficulty growth is significantly smoothed out.
- **Clear Goal:** The MOD’s target clear is Round 100, after which vanilla difficulty resumes. The official maximum is Round 110, and both rounds include easter eggs.
- **Faster Pacing:** Before Round 90, the next round may be randomly skipped; non-BOSS rounds also receive random speed boosts.
- **Leaderboards:** Added rankings for weapon damage and total kills.

## ⚙️ MOD Installation & Usage Tips

### Installation Guide

1. Extract the ZIP archive.
2. Copy the `UltimateZombieDefense_64_Data` folder into your game root directory and overwrite existing files.

Alternatively, manually replace the following file:

```
./UltimateZombieDefense_64_Data/Managed/Assembly-CSharp.dll
```

### Network Recommendation

> This MOD is intended for use in domestic/local multiplayer. It is not recommended to use a network accelerator to avoid high latency, unless you are playing with overseas players.
