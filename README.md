# UltimateZombieDefenseMOD
Ultimate Zombie Defense 16 players room MOD
# Content Description
1. Enhanced game experience, supporting up to 16 players online simultaneously.
2. Game difficulty automatically adjusts based on the number of players in the room.
3. Overall improvement of player-side attributes, with reasonable optimization of zombie strength.
# How to use?
Download the zip file and extract it to the game's root directory.
# Statement
This MOD is released for free and is intended for learning and communication purposes only. It is not affiliated with the official game.
