# 🧟 Ultimate Zombie Defense — 16 Players MOD

> *The horde is coming. This time, you won't face it alone.*

---

### ✨ What's New

- **16-Player Co-op** — Assemble a full squad and fight the undead together. The more survivors, the fiercer the battle.
- **Dynamic Difficulty Scaling** — The game intelligently adjusts zombie waves, health pools, and spawn rates based on the number of players in the room. No more boring easy runs or impossible lobbies.
- **Rebalanced Combat** — Player attributes have been comprehensively enhanced, while zombie strength has been carefully tuned to maintain a challenging yet fair experience.

### 📦 Installation

1. Download the `.zip` file
2. Extract its contents directly into the **game root directory**
3. Launch the game and enjoy
