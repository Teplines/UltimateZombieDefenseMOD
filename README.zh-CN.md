## 💎 玩家增益与强化

### 1. 复合成长（每 5 回合）

以下所有属性每 **5 回合** 会获得 **+5% 的累计增益**：

- 玩家生命值与护甲
- 大部分技能树属性
- 所有武器（伤害 / 射速 / 装弹速度 / 弹匣容量 / 总弹药）
- 所有建筑（耐久度 / 攻击伤害）
- 资源（金币 / 经验获取）

## 🧟 僵尸平衡与游戏进程

- 前期难度与官方原版一致；中后期难度增长被显著平滑。
- **第 100 回合** 被设定为本 MOD 的通关回合。
- 通关第 100 回合后，将恢复原版难度。官方最大波数上限为 **第 110 回合**。
- MOD第 100 回合和 110 回合 设有**通关彩蛋**。
- 本 MOD 为非 Boss 回合加入随机性，**加快游戏节奏**。
- **武器伤害排名** 每 2 波更新一次。
- **击杀数排行榜** 每 5 波更新一次。

## ⚙️ MOD 安装与使用建议

### 安装指南

1. 解压 ZIP 压缩包。
2. 将 `UltimateZombieDefense_64_Data` 文件夹复制到游戏根目录，并覆盖现有文件。

或者，手动替换以下文件：

```
./UltimateZombieDefense_64_Data/Managed/Assembly-CSharp.dll
```

### 网络建议

> 该 MOD 适合国内/本地多人联机使用。不建议使用网络加速器以避免高延迟，除非你正在与海外玩家联机。
